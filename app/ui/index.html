PsychoRando

An item randomizer for Psychonauts 2. Every collectible ends up somewhere new.

1

Point to your game and saves

PsychoRando needs your Psychonauts 2 install (it uses UE4SS, which you already have) and the folder with your save files.

2

Collectibles

Every collectible in the game is built into PsychoRando, so there's nothing to scan.

Rescan the game (only needed after a game update)

The mod opens every level inside the game and rebuilds the list. Start it, then keep the game on the title screen for about a minute. When it finishes, PsychoRando keeps the new list as its built-in data.

3

Pick an empty save slot

Randomized games always start fresh. Pick an empty slot, randomize it, then choose New Game in that slot. Slots with a regular save can't be randomized, and the randomizer only runs while a randomized slot is loaded.

4

Choose what gets shuffled

Everything you tick is pooled together and spread across every level. Untick something to leave it where the game put it.

Start

Loboto's Labyrinth is marked complete and its collectibles are left out of the shuffle.

The same seed and options always give the same layout, so you can race a friend.
